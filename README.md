# JAGUAR · Human Factors · Kinematics · Vehicle Ergonomics — for Rhino

Plugin gratuito para **Rhino 8 (Windows 10/11)**: maniquí de postura basado en SAE J826, Dreyfuss y ANSUR II para diseñar la ergonomía y el packaging de autos y motos, sin Grasshopper.
Free plugin for **Rhino 8 (Windows 10/11)**: a posture mannequin based on SAE J826, Dreyfuss and ANSUR II to design car and motorcycle ergonomics and packaging, without Grasshopper.

## Qué hace / What it does
- Maniquí P1–P99, hombre y mujer, 18 regiones ajustadas por estatura · P1–P99 mannequin, male/female, 18 regions scaled by height.
- 5 posturas de moto y 3 de auto, con casco; manos agarrando manillar o volante · 5 bike and 3 car postures, helmeted; hands grip the bar or wheel.
- Copiloto, hasta 6 pasajeros y pasajero de moto · Co-driver, up to 6 passengers and a helmeted pillion.
- Mapa de colores de cargas y fatiga (momentos articulares, tiempo, vibración, aceleración) · Colour map of loads and fatigue.
- Ángulos de visión para dimensionar el parabrisas · Vision angles to size the windshield.
- Panel plegable, español e inglés; el modelo es virtual y solo se hornea cuando tú lo decides · Collapsible panel, Spanish and English; the model is virtual and only baked when you decide.

## Instalación / Install
1. Descarga `JAGUAR-Installer.zip`, descomprime y cierra Rhino · Download `JAGUAR-Installer.zip`, unzip and close Rhino.
2. Ejecuta `JAGUAR-Setup.exe` (o `INSTALAR.cmd` si tu antivirus lo bloquea) · Run `JAGUAR-Setup.exe` (or `INSTALAR.cmd` if your antivirus blocks it).
3. Abre Rhino: aparece la barra JAGUAR; comando `Jaguar` · Open Rhino: the JAGUAR toolbar appears; command `Jaguar`.

El instalador aún no está firmado: Windows puede avisar («Más información → Ejecutar de todos modos») · The installer is not code-signed yet: Windows may warn.
